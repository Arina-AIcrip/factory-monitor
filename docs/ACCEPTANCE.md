# Проверка кейса № 8

Дата: 09.11.2026. Среда: Windows, Node.js 24.22.1, Microsoft Edge (автоматизация Playwright).

| Требование положения | Реализация | Проверка |
|---|---|---|
| Минимум 4 KPI | Выпуск, доступность, энергия, доля брака | Суммы сверены с линиями и интервалами графика автоматическими тестами |
| Два типа графиков | Линейный и столбчатый, Chart.js | Оба отображаются на desktop и mobile |
| Фильтры периода и объекта | 1/6/24 часа, все линии или отдельная | Проверены API и переключение браузером |
| Таблица событий | Время, объект, уровень, описание; до 20 записей | Границы окна, сортировка, отсутствие дублей и фильтрация проверены |
| Обновление без перезагрузки | REST polling каждые 3 секунды | В браузере зафиксирована смена версии снимка без навигации |
| Потеря и восстановление связи | Предупреждение, сохранённый снимок, повторы, сообщение восстановления | Проверены кнопка имитации и настоящее отключение сети через браузерный контекст |
| Синхронное изменение виджетов | Один JSON-снимок для всех блоков, отмена старого запроса | Смена фильтров, в том числе во время обрыва связи |
| Источник тестовых данных | Воспроизводимый генератор telemetry.mjs | Проверены повторяемость, допустимые диапазоны и изменение шага |
| Архитектура обмена | docs/ARCHITECTURE.md | Описаны API, контракты, интервалы и обработка ошибок |

Результат автоматических тестов: 5 из 5 прошли (`node --test tests/dashboard.test.mjs`).

Браузерная проверка: загрузка, автообновление, фильтры, имитация обрыва, отключение/включение сети браузера, восстановление актуальных фильтров, отсутствие JavaScript-ошибок. Размеры экранов: 1440×1100, 390×844, 768×1024. На мобильном и планшете нет горизонтальной прокрутки всей страницы; таблица имеет собственную горизонтальную прокрутку. Desktop и mobile скриншоты просмотрены визуально.

В комплекте: desktop.png, mobile.png, offline.png. Dockerfile предоставлен для удобства, сборка Docker в этой проверке не выполнялась. Интернет-публикация не выполнялась. Проверка реального промышленного оборудования не выполнялась: источник учебный.
