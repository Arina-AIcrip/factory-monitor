# Архитектура и API

Браузер → GET /api/dashboard?period=1h&object=all → HTTP-сервер → генератор учебной телеметрии → единый JSON-снимок → KPI / оба графика / линии / события.

## Состав

- server.mjs: маршрутизация, валидация фильтров, статические файлы из явного списка, HTTP-заголовки.
- telemetry.mjs: воспроизводимый генератор пятисекундных замеров и событий, агрегация выбранного окна.
- public/app.js: опрос, атомарное обновление виджетов из одного снимка, обработка ошибок, отмена устаревших запросов.
- public/style.css: адаптивная сетка, состояния связи, мобильная таблица.
- public/vendor: локальная версия Chart.js и лицензия. Обновление данных графиков: https://www.chartjs.org/docs/latest/developers/updates.html.

## Контракты

GET /api/health → 200 {"status":"ok","mode":"demo"}.

GET /api/objects → 200 массив объектов (id, name, code, capacity).

GET /api/dashboard?period=1h&object=all → 200:

- mode: demo; revision: номер пятисекундного шага; generatedAt: время ответа Unix ms.
- window: start/end Unix ms; измерения входят в интервал (start, end].
- filters: period (1h/6h/24h), object (all/cutting/assembly/packing).
- kpi: units, rejected, energy (кВт·ч), defectRate (%), availability (%).
- bins: t (начало интервала), units, energy; 60 точек для часа, 48 для 6/24 часов.
- lines: id, name, code, units, rejected, energy, availability, temperature (°C), status (running/warning/stopped).
- events: до 20 событий с id, t, object, name, severity (info/warning/critical), message; сортировка по убыванию времени.

Значения фильтров по умолчанию: 1h, all. Неизвестный фильтр → 400 с полем error; неизвестный маршрут → 404; метод кроме GET → 405; внутренняя ошибка → 500. Ответы не кешируются.

## Отказоустойчивость клиента

Опрос раз в 3 секунды. Тайм-аут запроса 7 секунд. При ошибках задержки 3, 6, 12, 15 секунд и далее 15 секунд. Последний успешный снимок остаётся виден с предупреждением и указанием его фильтров. До первого ответа отображаются прочерки. Успешный ответ сбрасывает счётчик ошибок и показывает восстановление связи. Смена фильтра отменяет предыдущий запрос; счётчик последовательности игнорирует запоздалые ответы. Кнопка имитации использует тот же путь обработки ошибки, не останавливая сервер для других клиентов.

## Формулы генератора

Синусоидальные колебания выпуска и температуры, циклические остановки и редкие дефектные изделия дают повторяемую нагрузку. Суммы считаются по всем пятисекундным замерам выбранных линий за окно. Доступность — количество работающих замеров / число всех замеров. В одной версии снимка все виджеты согласованы. События — отдельная учебная последовательность, не алгоритм выявления аварий по измерениям.

Не заявляются промышленная надёжность или нагрузочная производительность. Расчёт истории выполняется в памяти на каждый запрос; для реального потока его нужно заменить хранилищем/агрегацией телеметрии.
